# 🧶 Dinha Crochê

> Landing page responsiva desenvolvida para apresentação de produtos artesanais em crochê, galerias de fotos, depoimentos e canal direto para encomendas.

📍 **Acesse o site online:** [devarthurlima.github.io/dinhaCroche](https://devarthurlima.github.io/dinhaCroche/)

---

## ✨ Funcionalidades

- 📱 **Design Responsivo:** Adaptado para navegação em computadores, tablets e dispositivos móveis.
- 🖼️ **Galeria de Produtos:** Exibição dinâmica de peças e categorias de crochê.
- 💬 **Sessão de Depoimentos & FAQ:** Lista interativa com perguntas frequentes de clientes.
- 🛍️ **Chamada para Ação (CTA):** Botões diretos para facilitar o pedido/encomenda.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layouts em Flexbox/Grid e responsividade via `@media queries`.
- **Google Fonts:** Tipografia personalizada (*Kaushan Script*, *Playwrite DE SAS*, *Comic Neue*, *Work Sans*).
